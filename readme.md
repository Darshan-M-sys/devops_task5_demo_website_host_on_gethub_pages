# NovaFlow | Demo Website

This project is a demo website built as part of an internship task to learn how to host a static website using GitHub Pages.

## Live Demo

Visit the deployed site here:

https://darshan-m-sys.github.io/devops_task5_demo_website_host_on_gethub_pages/

## Project Overview

NovaFlow is a modern SaaS-style landing page designed to showcase a product or startup brand. The site includes:

- Responsive layout for desktop and mobile devices
- Hero section with strong product messaging
- Feature, workflow, pricing, and testimonial sections
- Clean modern UI with smooth reveal animations
- Mobile-friendly navigation menu

## Internship Task Context

This website was created as a hands-on internship assignment focused on:

- building a simple static website
- structuring HTML, CSS, and JavaScript files
- deploying the project on GitHub Pages
- learning how to publish a website publicly from a GitHub repository

## Files

- `index.html` – page structure and content
- `style.css` – visual styling and responsive layout
- `script.js` – interactive effects and menu behavior

## Run Locally

Open `index.html` directly in a browser, or serve the folder locally using:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deployment

The site is hosted using GitHub Pages, which makes it easy to publish static websites directly from a repository.
